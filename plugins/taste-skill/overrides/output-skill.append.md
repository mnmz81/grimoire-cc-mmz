
## Scope (grimoire override)

This skill governs **deliverables** — code, files, components, and other requested artifacts. It does **not** govern conversational prose.

- If the user has a terse-output style active (e.g. `caveman`), keep chat prose compressed. Completeness ≠ verbosity: ship every requested file/function in full, then report it in as few words as the active style allows.
- The banned prose phrases ("for brevity", "and so on") are banned only when they stand in for omitted deliverable content — not as a ban on concise explanation.
